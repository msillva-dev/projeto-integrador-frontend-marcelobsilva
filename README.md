# projeto-integrador-frontend-marcelobsilva
O Sabores & Receitas é um projeto de site de culinária desenvolvido na disciplina de Desenvolvimento Front-end para Web.

Seu objetivo é ajudar pessoas a encontrar receitas de maneira simples, prática e organizada.

O site pretende facilitar a busca por pratos, apresentar ingredientes e explicar o modo de preparo de forma clara, inclusive para quem está começando a cozinhar.

Ao longo da disciplina, serão desenvolvidas novas funcionalidades, considerando a acessibilidade, a facilidade de navegação e a experiência dos usuários.
